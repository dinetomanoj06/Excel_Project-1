# Excel_Project#1 -World Bank Development Indicators Dashboard

An interactive Excel dashboard built using World Bank development indicators.

The dashboard allows users to select a country and year and dynamically explore
key development indicators such as GDP, GDP per capita, life expectancy,
internet usage, unemployment, birth rate and death rate.

## Features

- Interactive country and year selection
- Global benchmark comparison
- Dynamic KPI cards
- Historical trend analysis
- Data validation controls
- Excel charts and formulas

## Dataset

World Bank development indicators containing economic, demographic and
development-related metrics across countries and years.

## Tools Used

- Microsoft Excel
- Excel Tables
- XLOOKUP
- IF / SUMIFS
- Data Validation
- Charts
- Dynamic dashboard design
- KPI cards
